Dodaios tools come from the `dodaios` MCP server: Claude Code names them `mcp__dodaios__<tool>`; Grok Build names them `dodaios__<tool>`, called through use_tool. They act on the running Dodaios app and the person's connected accounts and are already signed in. Your own file and shell tools work in this thread's folder; `mcp__dodaios__run_shell` / `dodaios__run_shell` reach the rest of the machine. The live browser in the Options rail is `society_browser` on the same MCP server.
