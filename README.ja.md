Dodaios は、ローカルにインストールして使うオープンソースの Python プログラムで、
Windows、macOS、Linux 上でデスクトップアプリとして、またはブラウザー UI 付きの
ヘッドレスサーバーとして動作します。パーソナル AI アシスタントを、コンピューターで
行う作業のコントロールセンターに変えます。

その中心にあるのは、音声（ウェイクワード、ディクテーション、リアルタイムの音声会話、
そして早期プレビューとして電話）、チャット、またはペアリングしたスマートフォンから
話しかけられる「リード」アシスタントです。特定のプロバイダーに縛られず、Claude、OpenAI、
Gemini、ローカルの Ollama モデルで動作します。ツール、コンピューター操作、プラグイン、
CLI、MCP サーバーを通じて自らタスクをこなします。何より、作業をコーディングエージェントに
引き渡します。エージェントは組み込みの Agentic IDE の中で、本物の Claude Code や Codex の
ターミナルとして並んで動作し、あなたのコンピューター上でも、SSH 経由で自分のサーバー上でも
実行できます。それぞれに名前で呼びかけられるコールサインがあり、Git 連携とタスクの分割も
備えています。さらに、互いにメッセージを送り合う、名前付きで永続的なエージェントの
「ソサエティ」もあります。

長期にわたる作業は、メモリー（あなた自身、あなたの周りの人々、アシスタント自身の
ペルソナについて）、常設タスク、ワークフロー、スキル、そしてオプトインの
生活事務でカバーされます。アシスタントは、ドキュメント、スライド、シート、
ダッシュボードなどの成果物を自ら作り、足りないスキル、ルーティン、エージェントを
提案して構築することもできます。トラストレイヤーが厳格な上限を設けており、Bypass
permissions 以外のモードでは、送金、認証情報の取り扱い、完全な削除、新しい相手への
最初の連絡には、必ずあなたの確認が必要です。つまり Dodaios は、音声で操作でき、
ローカルで動作する AI エージェントのためのオペレーティングシステムであり、1 つの
アシスタントを、あなたのモデル、コーディングエージェント、そしてあなた自身の
コンピューターの指揮者にします。

## インストール

macOS と Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.sh | bash
```

Windows（PowerShell で）：

```powershell
irm https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.ps1 | iex
```

インストーラーは独自の Python 環境をセットアップし、ランチャーを追加して
アプリを開きます。初回起動時には、アシスタントに名前を付け（これはウェイク
ワードにもなります）、モデルを 1 つ接続し、どのように話しかけるかを選びます。
コーディング作業をするには、Claude Code や Codex などのコーディングエージェントを
少なくとも 1 つインストールし、サインインしてください。

```bash
dodaios            # start the desktop app
dodaios update     # install the newest release
```

各リリースのチェックサムは `installers-SHA256SUMS.txt` に記載されています。
インストーラーにはまだ署名がありません。Windows では警告が表示され、macOS では
「システム設定」の「プライバシーとセキュリティ」で、アプリを一度許可するよう求められます。
現状については
[コード署名ポリシー](https://github.com/Dodaios/Dodaios/blob/main/docs/code-signing-policy.md)
に記載されています。

pipx では、デスクトップランチャーのない、より小さなサーバーパッケージが入ります。
画面のない Linux サーバーでは、インストーラーに `--headless` を指定でき、
`dodaios serve` はブラウザーインターフェースだけを起動します：

```bash
pipx install dodaios
curl -fsSL https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.sh | bash -s -- --headless
dodaios serve      # browser interface only, for a server without a screen
```

Dodaios は 64 ビットの Windows、macOS、glibc ベースの Linux で動作します。ターミナル
インストーラーは x86-64 と Arm64 で動作し、Python 3.11〜3.14 と Git が必要です。
不足している Python は取得し、不足している Git はインストールを提案します。
グラフィックカードは必須ではありません。現時点で実機での承認が記録されているのは Windows 11 だけです。

## プランとキー

Dodaios は無料です。Dodaios のアカウントも有料プランもありません。モデルへの
アクセスを販売することはなく、あなたの代わりにサインインすることもありません。
各コーディングエージェントの公式のコマンドラインツールを起動し、それぞれには
あなた自身がサインインするため、エージェントはすでにお持ちのプランとキーで動作します。
たとえば Claude Code には、有料の Claude プランが必要です。各サービスの利用は、
そのサービス自身の規約に従います。
[プロバイダーと API キー](https://github.com/Dodaios/Dodaios/blob/main/docs/product/personalize-and-connect/providers-and-api-keys.md)

## 知っておきたいこと

- **あなたのデータ。** チャット、メモリー、ドキュメント、設定は、Dodaios を実行している
  コンピューター上のファイルです。モデルや接続されたサービスには、リクエストのうち
  その担当部分に必要なものだけが渡されます。Google、Slack、Figma の
  プラグインへのサインインは、プロジェクトが運営する小さなトークンサービスを経由します。
  [プライバシーとローカルデータ](https://github.com/Dodaios/Dodaios/blob/main/docs/product/privacy-safety-and-support/privacy-and-local-data.md)
- **先に確認する。** 新しいチャットは、何も確認されない Bypass permissions で始まります。
  確認するモードを選ぶと、上記の 4 つの厳格な上限は常にあなたの承認を待ちます。
  [安全性と承認](https://github.com/Dodaios/Dodaios/blob/main/docs/product/privacy-safety-and-support/safety-and-approvals.md)
- **未完成の部分。** 電話には自分の Twilio 番号が必要で、早期プレビューの段階です。
  ほとんどのプラグインには、まだ Preview バッジが付いています。スマートフォンアプリは、
  あなたのコンピューターが配信する Web アプリです。
