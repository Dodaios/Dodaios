একটি টার্মিনালে Claude Code, আরেকটিতে Codex, আর একটি চ্যাট ট্যাব যেখানে আপনি পরিকল্পনা এদিক-ওদিক কপি করেন। Dodaios এর অবসান ঘটায়। এটি আপনার সব কোডিং এজেন্টের উপরে একটি স্তর: আপনি ভয়েস বা চ্যাটে বলেন কী চান, আর একটি অ্যাসিস্ট্যান্ট বাকিটা সামলায়। এটি ব্রিফ লেখে, বিল্ট-ইন Agentic IDE-তে সঠিক এজেন্ট চালু করে, কাজের সময় নজর রাখে, আর কাজ শেষ হলে বা আপনাকে দরকার হলে জানায়। একসাথে পাঁচটি এজেন্ট চালান, তবুও প্রতিটি ঠিক কী করেছে তা জানুন।

ওপেন সোর্স, এবং আপনার কম্পিউটারে চলে। আপনার Claude বা ChatGPT সাবস্ক্রিপশন, Claude, OpenAI ও Gemini-এর API কী, অথবা লোকাল Ollama মডেলের সাথে কাজ করে।

## ইনস্টল

macOS আর Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.sh | bash
```

Windows, PowerShell-এ:

```powershell
irm https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.ps1 | iex
```

ইনস্টলার নিজের আলাদা Python এনভায়রনমেন্ট সেট আপ করে, একটি লঞ্চার যোগ করে আর অ্যাপটি
খুলে দেয়। প্রথমবার চালু করলে আপনি অ্যাসিস্ট্যান্টকে একটি নাম দেন (এটিই ওয়েক ওয়ার্ড),
একটি মডেল যুক্ত করেন আর বেছে নেন তার সঙ্গে কীভাবে কথা বলবেন। কোডিংয়ের কাজের জন্য অন্তত
একটি কোডিং এজেন্ট, যেমন Claude Code বা Codex, ইনস্টল করে তাতে সাইন ইন করুন।

```bash
dodaios            # start the desktop app
dodaios update     # install the newest release
```

<summary>ডেস্কটপ ইনস্টলার, pipx আর সার্ভার</summary>

সর্বশেষ রিলিজ থেকে আপনার সিস্টেমের ইনস্টলার ডাউনলোড করুন:

| Windows | macOS | Linux |
| --- | --- | --- |
| [Dodaios-Setup-x64.exe](https://github.com/Dodaios/Dodaios/releases/latest/download/Dodaios-Setup-x64.exe) | [Apple Silicon](https://github.com/Dodaios/Dodaios/releases/latest/download/Dodaios-macOS-arm64.dmg) · [Intel](https://github.com/Dodaios/Dodaios/releases/latest/download/Dodaios-macOS-x64.dmg) | [AppImage, x86_64](https://github.com/Dodaios/Dodaios/releases/latest/download/Dodaios-Linux-x86_64.AppImage) |

প্রতিটি রিলিজের checksum `installers-SHA256SUMS.txt`-এ দেওয়া থাকে। ইনস্টলারগুলো এখনও
সাইন করা নয়: Windows একটি সতর্কবার্তা দেখায়, আর macOS আপনাকে System Settings-এ,
Privacy & Security-র ভেতরে, অ্যাপটিকে একবার অনুমতি দিতে বলে। এই কাজ কতদূর এগোল, তা
[কোড সাইনিং পলিসি](https://github.com/Dodaios/Dodaios/blob/main/docs/code-signing-policy.md)-তে
লেখা আছে।

pipx দিয়ে আপনি ছোট সার্ভার প্যাকেজটি পান, যাতে ডেস্কটপ লঞ্চার থাকে না। স্ক্রিন ছাড়া
Linux সার্ভারে ইনস্টলার `--headless` নেয়, আর `dodaios serve` শুধু ব্রাউজার ইন্টারফেস
চালু করে:

```bash
pipx install dodaios
curl -fsSL https://raw.githubusercontent.com/Dodaios/Dodaios/main/install/install.sh | bash -s -- --headless
dodaios serve      # browser interface only, for a server without a screen
```

Dodaios চলে 64-বিট Windows, macOS আর glibc-ভিত্তিক Linux-এ। টার্মিনাল ইনস্টলার x86-64
আর Arm64-এ কাজ করে এবং এর জন্য Python 3.11 থেকে 3.14 আর Git লাগে; Python না থাকলে
এটি নিজেই এনে নেয়, আর Git না থাকলে ইনস্টল করার প্রস্তাব দেয়। গ্রাফিক্স কার্ড বাধ্যতামূলক
নয়। এখন পর্যন্ত শুধু Windows 11-এই আসল মেশিনে পরীক্ষার পর অনুমোদন রেকর্ড করা আছে।
[ইনস্টল গাইড](https://github.com/Dodaios/Dodaios/blob/main/docs/product/start-here/install-dodaios.md) ·
[প্ল্যাটফর্ম সাপোর্ট](https://github.com/Dodaios/Dodaios/blob/main/docs/product/reference/platform-support.md) ·
[সার্ভারে চালানো](https://github.com/Dodaios/Dodaios/blob/main/docs/headless-vps-deployment.md)

## আপনার প্ল্যান আর API key

Dodaios-এর কোনো খরচ নেই: কোনো Dodaios অ্যাকাউন্ট নেই, কোনো পেইড টিয়ার নেই। এটি মডেলের
অ্যাক্সেস বিক্রি করে না এবং কখনও আপনার হয়ে সাইন ইন করে না। এটি প্রতিটি কোডিং এজেন্টের
অফিশিয়াল কমান্ড-লাইন টুল চালু করে, আর প্রতিটিতে আপনি নিজে সাইন ইন করেন, তাই এজেন্টগুলো
আপনার আগে থেকে থাকা প্ল্যান আর key দিয়েই চলে। যেমন, Claude Code-এর জন্য পেইড Claude
প্ল্যান লাগে। প্রতিটি সার্ভিসের ব্যবহার সেই সার্ভিসের নিজস্ব শর্ত মেনে হয়।
[প্রোভাইডার আর API key](https://github.com/Dodaios/Dodaios/blob/main/docs/product/personalize-and-connect/providers-and-api-keys.md)

## জেনে রাখা ভালো

- **আপনার ডেটা।** চ্যাট, মেমোরি, ডকুমেন্ট আর সেটিংস ফাইল হিসেবে থাকে সেই কম্পিউটারে,
  যেখানে Dodaios চলে। কোনো মডেল বা যুক্ত সার্ভিস একটি রিকোয়েস্টে নিজের অংশের জন্য যা
  দরকার, শুধু সেটুকুই পায়। Google, Slack বা Figma প্লাগইনে সাইন ইন হয় একটি ছোট token
  সার্ভিসের মধ্য দিয়ে, যেটি এই প্রজেক্ট চালায়।
  [প্রাইভেসি আর লোকাল ডেটা](https://github.com/Dodaios/Dodaios/blob/main/docs/product/privacy-safety-and-support/privacy-and-local-data.md)
- **আগে জিজ্ঞেস করা।** নতুন চ্যাট শুরু হয় Bypass permissions-এ, যেখানে কিছুই জিজ্ঞেস
  করা হয় না। জিজ্ঞেস করে এমন একটি মোড বেছে নিলে, ওপরের চারটি কড়া সীমা সবসময় আপনার
  হ্যাঁ-র অপেক্ষায় থাকে।
  [নিরাপত্তা আর অনুমোদন](https://github.com/Dodaios/Dodaios/blob/main/docs/product/privacy-safety-and-support/safety-and-approvals.md)
- **এখনও শেষ হয়নি।** ফোন কলের জন্য আপনার নিজের Twilio নম্বর লাগে, আর এটি এখনও আর্লি
  প্রিভিউ। বেশিরভাগ প্লাগইনে এখনও Preview ব্যাজ লাগানো আছে। ফোন অ্যাপটি একটি ওয়েব অ্যাপ,
  যা আপনার কম্পিউটার সার্ভ করে।
